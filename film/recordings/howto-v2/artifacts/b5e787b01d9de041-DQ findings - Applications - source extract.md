## Suggested fixes and pipeline DQ rules (High findings)

1. **APP_ID duplicate (row 36).** Source: confirm with the source system owner whether AP1001034 is a re-extracted or genuinely duplicated application. Pipeline: *APP_ID must be unique; keep the row with the latest LAST_UPD_TS and send the others to a quarantine table.*
2. **CLIENT_ID orphan (row 24).** Source: check whether client C-1999 is missing from the Clients extract or is an invalid key. Pipeline: *CLIENT_ID must exist in Clients; quarantine orphans (or load against an "Unknown client" member) and report them.* Load Clients before Applications.
3. **APP_TYPE blank (rows 13, 28).** Source: make APP_TYPE mandatory on the application form. Pipeline: *APP_TYPE not null and in NEW, RENEWAL, AMEND; reject the row to quarantine.* Do not default it without a business decision.
4. **SUBMIT_DT invalid dates (rows 8, 20).** Source: correct the two dates and enforce one date format (yyyy-MM-dd) in the extract. Pipeline: *SUBMIT_DT must parse with format 'yyyy-MM-dd'; reject the row to a quarantine table.* Don't guess day/month for 15/13/2026.
5. **STATUS_CD not allowed (row 32: PENDING).** Source: ask the business whether PENDING is a legacy status that should map to SUBMITTED or IN_REVIEW, or should be added to the dictionary. Pipeline: *STATUS_CD in DRAFT, SUBMITTED, IN_REVIEW, APPROVED, REFUSED; quarantine others* (or apply an agreed mapping table).

Medium findings to review: APP_ID row 39 is lower case (an `upper` + trim rule would fix it); FEE_AMT row 16 (12,000.00) should be confirmed with the business as a real fee or a keying error (e.g. 120.00).

```python
# Profiling script generated by Lumen from a sample. Run it in a lower-environment Fabric notebook.
from pyspark.sql import functions as F

df = spark.read.table("bronze.applicationssourceextract")
total = df.count()
rows = []
for c in ["APP_ID","CLIENT_ID","APP_TYPE","SUBMIT_DT","STATUS_CD","FEE_AMT","PROVINCE_CD","EMAIL_ADDR","INTERNAL_NOTE_TXT","LAST_UPD_TS"]:
    s = df.agg(F.sum(F.when(F.col(c).isNull() | (F.trim(F.col(c).cast("string")) == ""), 1).otherwise(0)).alias("nulls"), F.countDistinct(c).alias("distinct"), F.min(c).alias("min"), F.max(c).alias("max")).first()
    rows.append((c, total, s["nulls"], s["distinct"], str(s["min"]), str(s["max"])))
display(spark.createDataFrame(rows, ["column", "rows", "nulls", "distinct", "min", "max"]))

# Data dictionary rules: rows that break each rule
checks = {
    "APP_ID required": F.col("APP_ID").isNull() | (F.trim(F.col("APP_ID")) == ""),
    "APP_ID pattern": F.col("APP_ID").isNotNull() & ~F.col("APP_ID").rlike("^(?:AP[0-9]{7})$"),
    "CLIENT_ID required": F.col("CLIENT_ID").isNull() | (F.trim(F.col("CLIENT_ID")) == ""),
    "APP_TYPE required": F.col("APP_TYPE").isNull() | (F.trim(F.col("APP_TYPE")) == ""),
    "APP_TYPE allowed values": F.col("APP_TYPE").isNotNull() & ~F.col("APP_TYPE").isin(["NEW","RENEWAL","AMEND"]),
    "SUBMIT_DT required": F.col("SUBMIT_DT").isNull() | (F.trim(F.col("SUBMIT_DT")) == ""),
    "SUBMIT_DT valid date": F.col("SUBMIT_DT").isNotNull() & F.to_date(F.col("SUBMIT_DT")).isNull(),
    "STATUS_CD required": F.col("STATUS_CD").isNull() | (F.trim(F.col("STATUS_CD")) == ""),
    "STATUS_CD allowed values": F.col("STATUS_CD").isNotNull() & ~F.col("STATUS_CD").isin(["DRAFT","SUBMITTED","IN_REVIEW","APPROVED","REFUSED"]),
    "FEE_AMT required": F.col("FEE_AMT").isNull() | (F.trim(F.col("FEE_AMT")) == ""),
    "PROVINCE_CD allowed values": F.col("PROVINCE_CD").isNotNull() & ~F.col("PROVINCE_CD").isin(["NL","PE","NS","NB","QC","ON","MB","SK","AB","BC","YT","NT","NU"]),
    "LAST_UPD_TS required": F.col("LAST_UPD_TS").isNull() | (F.trim(F.col("LAST_UPD_TS")) == ""),
    "LAST_UPD_TS valid timestamp": F.col("LAST_UPD_TS").isNotNull() & F.to_timestamp(F.col("LAST_UPD_TS")).isNull(),
}
for name, cond in checks.items():
    print(name, df.filter(cond).count())
print("APP_ID duplicates", df.groupBy("APP_ID").count().filter("count > 1").count())
print("CLIENT_ID orphans", df.join(spark.read.table("bronze.clients").select(F.col("CLIENT_ID").alias("_k")), F.col("CLIENT_ID") == F.col("_k"), "left_anti").filter(F.col("CLIENT_ID").isNotNull()).count())
```
