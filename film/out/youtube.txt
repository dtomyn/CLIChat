TITLE
AI Agents for Everyone: Microsoft Project & Excel Without the Terminal | Lumen Demo

DESCRIPTION
Your whole team has VS Code, GitHub Copilot and the Claude command line. Powerful tools, but most business analysts and project managers don't want to live in a terminal. Lumen puts the same AI agents and skills behind a friendly chat window that runs on your own computer.

In this demo, two people on a (fictional) CRM migration project use Lumen to get real work done:

🧭 Marcus, Business Analyst
• Picks the Requirements Coach and gets user stories with Given/When/Then acceptance criteria in seconds
• Describes a new assistant in one sentence, and Lumen drafts its name, instructions and example requests, and switches on the right skills

📋 Priya, Project Manager
• Runs a health check on a Microsoft Project plan: RAG status, critical path, slippage against baseline and over-allocated people
• Updates the plan straight from an Excel progress sheet, saved as a new version so the original is never overwritten
• Has the budget tracker reviewed cell by cell: categories going over, contingency left, and a mismatch between two sheets
• Turns the plan into a colour-coded Excel tracker with a Gantt chart

Also shown: Lumen's AI engine is pluggable (Claude Code CLI today, GitHub Copilot CLI one setting away), and every assistant and skill exports straight into VS Code.
