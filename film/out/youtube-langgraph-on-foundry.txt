A Long List of Agent Ideas, and One Evening to Find Out: 23 LangGraph Agents on Microsoft Foundry

A client and I were deciding where a long list of AI agents would live, and landing on simple markdown agents in GitHub Copilot. But if they were ever built as code, LangGraph was the approved framework. So before that window closed, I spent an afternoon and an evening finding out what it would really take.

This video shows how I built 23 LangGraph agents, deployed them as Microsoft Foundry hosted agents, what Foundry adds to make them enterprise-ready, and how an app consumes them.

What's covered:
- The approach: one shared core and one graph shape for every agent
- The graph code: add_edge, add_conditional_edges, a Send fan-out (one extraction per section, in parallel) and a self-check loop
- Typed model calls, human approval with interrupt(), and tests with the model scripted out
- Deploying all 23 with one azd deploy
- In the Foundry portal: Entra agent identity, an access-controlled Responses endpoint, guardrails, tracing, monitoring and cost
- AI red teaming that found one real failure, the layered fix, and a clean re-scan
- Lumen, a chat app I extended, calling the agents and handling approvals, plus the provider code behind it
