Inside the SDLC agents: how the LangGraph code is built, and how Lumen talks to it

A code walkthrough of a proof of concept: 23 software-delivery agents built on one shared LangGraph core, with shared contracts and connectors. It covers three representative agents, the tests, deployment to Microsoft Foundry hosted agents, and Lumen's Foundry engine. Every excerpt is real code with its real line numbers.
