TITLE
AI Agents for Everyone: Project, Excel, Word and a Traceable Delivery Lifecycle | Lumen Demo

DESCRIPTION
Your whole team has VS Code, GitHub Copilot and the Claude command line. Powerful tools, but most business analysts, project managers and delivery leads don't want to live in a terminal. Lumen puts the same AI agents and skills behind a friendly chat window that runs on your own computer.

In this demo, three people use Lumen to get real work done:

🧭 Marcus, Business Analyst
• Searches the agent picker in the message box, picks the Requirements Coach and starts from one of its suggested prompts
• Gets user stories with Given/When/Then acceptance criteria in seconds, and follows a suggested next step with one click
• Retries, branches, rates or exports any reply (Word, PowerPoint or Markdown), and saves this one as a Word document
• Searches nearly forty built-in agents, then describes a new one in a sentence; Lumen drafts its name, instructions and example requests, and switches on the right skills

📋 Priya, Project Manager
• Sets up a practice project from the Samples page in one click
• Runs a health check on a Microsoft Project plan: RAG status, critical path, slippage against baseline and the bottleneck
• Copies any table straight into Excel or Outlook, and sets the health check to repeat every Monday at 9:00 (listed under Tasks)
• Updates the plan straight from an Excel progress sheet, saved as a new version, then uses See changes to view every task field before and after
• Turns the plan into a colour-coded Excel tracker with a Gantt chart

🧬 Dana, Delivery Lead
• Runs a traceability check on the program's traceability workbook: coverage per layer, stories that would build the wrong thing, broken links, design bypass and source conflicts, each with its cell reference and owner
• Reshapes the lifecycle workflow by dragging technical design alongside functional design, so both run side by side and stories wait for both
• Starts a guided lifecycle run with the source documents pinned to each stage, runs an advisory traceability check at the gate, then approves, which stamps her name and the time on the output and makes both design stages ready to start

Also shown: Insights (thumbs up and down per agent and prompt, kept on your computer), Ask about Lumen (it knows every agent, prompt, workflow and schedule), a pluggable AI engine (Claude Code today, GitHub Copilot one setting away), connections to Azure DevOps and SharePoint & Microsoft 365, and exporting agents and prompts to Microsoft 365 Copilot and VS Code.
