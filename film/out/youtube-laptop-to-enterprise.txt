From laptop to enterprise: LangGraph agents on Microsoft Foundry hosted agents

A LangGraph agent runs on your laptop in an afternoon. Getting it in front of a whole organization, safely, is the real project. This video follows 23 LangGraph agents from a developer's laptop into Microsoft Foundry, and answers the six questions an enterprise architect will ask along the way: Where does it run? Who is it? Who can call it? Where do people use it? Is it safe? Can we see what it did? Each answer is shown where it lives in the Foundry portal, with the navigation to get there.

Notes
- Synthetic data, fictional organization (Contoso), a proof of concept.
- Ways in: guardrails apply to every model deployment. Tracing, monitoring and evaluations are built in for Foundry agents; an app that calls a model deployment directly opts in through OpenTelemetry and the evaluation SDK. Workflow agents orchestrate prompt agents; hosted agents orchestrate in their own code.
- At the time of recording, AI red teaming reports open in the classic Foundry view (New Foundry switched off).
- Agent replies in Lumen are real responses from the hosted agents, replayed for pacing. Lumen calls each agent's Responses endpoint with the user's own Azure sign-in.
- Narration: Kokoro text-to-speech (af_heart). Captions: lumen-laptop-to-enterprise.srt / .vtt.
