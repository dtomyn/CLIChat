TITLE
AI Agents for Everyone: Project, Excel, Word and a Traceable Delivery Lifecycle | Lumen Demo

DESCRIPTION
Your whole team has VS Code, GitHub Copilot and the Claude command line. Powerful tools, but most business analysts, project managers and delivery leads don't want to live in a terminal. Lumen puts the same AI agents and skills behind a friendly chat window that runs on your own computer.

In this demo, three people use Lumen to get real work done:

🧭 Marcus, Business Analyst
• Picks the Requirements Coach and gets user stories with Given/When/Then acceptance criteria in seconds
• Follows a suggested next step with one click; retries, branches, rates or saves any reply
• Saves the answer as a Word document with real headings, lists and tables
• Describes a new assistant in one sentence, and Lumen drafts its name, instructions and example requests, and switches on the right skills

📋 Priya, Project Manager
• Runs a health check on a Microsoft Project plan: RAG status, critical path, slippage against baseline and the bottleneck
• Copies any table straight into Excel or Outlook, and sets the health check to repeat every Monday at 9:00
• Updates the plan straight from an Excel progress sheet, saved as a new version, then uses See changes to view every task field before and after
• Turns the plan into a colour-coded Excel tracker with a Gantt chart

🧬 Dana, Delivery Lead
• Runs a traceability check on the program's traceability workbook: coverage per layer, stories that would build the wrong thing, broken links, design bypass and source conflicts, each with its cell reference and owner
• Starts a guided lifecycle run (refine requirements → functional design → technical design → stories) with the source documents pinned to each stage
• Runs an advisory traceability check at the gate, then approves, which stamps her name and the time on the output and unlocks the next stage

Also shown: Insights (thumbs up and down per assistant and quick start, kept on your computer), a pluggable AI engine (Claude Code CLI today, GitHub Copilot CLI one setting away), and every assistant and skill exporting straight into VS Code.
